# Live domain admin check

Source checked: https://fyzen-lab.uz/admin.html

On 2026-08-26, the live domain returned an older standalone FYZEN-LAB Admin Panel with a password field (`adminPassInput`) and a `KIRISH` button. It did not return the current Manus OAuth-protected admin.html or the new Telegram Mini App deployment. The page title was `FYZEN-LAB - Admin Panel`. Therefore `fyzen-lab.uz` is currently serving a different/older deployment and should not be used as the Mini App URL until the Fyzen Lab project is published and the domain is bound to that deployment.
